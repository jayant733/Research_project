# Security Policy

This document defines how we handle security vulnerabilities in the Adaptive Privacy Orchestrator project.

## Supported Versions

Only the latest release version on the `main` branch is actively supported with security patches.

| Version | Supported |
| ------- | --------- |
| >= 0.1.x| Yes       |
| < 0.1.0 | No        |

## Reporting a Vulnerability

We take system security, privacy leaks, and cryptographic vulnerabilities seriously. If you discover a vulnerability:

1. **Do not** open a public issue.
2. Send a detailed report describing the vulnerability, proof of concept, and impact to the project maintainers at `security@adaptive-privacy-orchestrator.local` (or file a private security advisory on GitHub).
3. We will acknowledge receipt of your report within 48 hours and coordinate a public release patch timeline.
